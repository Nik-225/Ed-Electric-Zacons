# Інтерактивний додаток з вивчення основних законів електротехніки

Вітаємо у інтерактивному додатку для вивчення основних законів електротехніки! Цей додаток розроблений, щоб допомогти вам зрозуміти та застосовувати ключові електротехнічні закони за допомогою інтерактивних демонстрацій, калькуляторів та тестів.

Цей додаток охоплює наступні теми:

* **Закон Ома:** Для ділянки кола та повного кола.
* **Закони Кірхгофа:** Для розрахунку складних електричних мереж.
* **Закон Джоуля-Ленца:** Про теплову дію струму.
* **Закон електромагнітної індукції Фарадея:**

Для кожної теми додаток містить:

* **Інтерактивні демонстрації:** Візуалізація законів у дії.
* **Калькулятори:** Можливість розрахунків параметрів електричних кіл.
* **Тести:** Перевірка знань та закріплення матеріалу.

## Встановлення та запуск

1.  **Завантажте репозиторій:**  `git clone <посилання на репозиторій>`
2.  **Перейдіть до директорії проекту:** `cd <назва директорії>`
3.  **Відкрийте файл `index.html` у вашому браузері.**

## Використання

Після відкриття додатку, ви побачите головне меню з переліком тем.  Виберіть необхідну тему, щоб перейти до інтерактивних елементів, калькуляторів та тестів.  Дотримуйтесь інструкцій на сторінках для взаємодії з додатком.
